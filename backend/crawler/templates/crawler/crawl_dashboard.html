Cakupan: on-demand crawl

Triggers metadata discovery → coverage confirmation → data ingestion in one pass, in the background. Each call is rate-limited against BPS, so a batch can take a few minutes — refresh this page to see progress. max_subjects is a resume cursor: it picks the next not-yet-crawled subjects each run, so repeated clicks make forward progress instead of re-fetching the same ones. Vervar (region-breakdown metadata) is skipped by default — it's not needed for coverage confirmation or data ingestion and costs ~45s/variable; only tick it if you specifically want that table filled in.
